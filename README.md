# AI-Powered Resume Screening System

This project leverages AI agents built with the **Swarms** framework and **Ollama-hosted LLMs** (running locally) to analyze and rank candidate resumes based on multiple key criteria. It aims to assist recruiters in identifying top talent efficiently and privately — without relying on external APIs.

## 🔍 Features

- Automatic parsing and semantic analysis of resumes
- Local language models via **Ollama** (no cloud dependencies)
- Intelligent ranking based on:
  - ✅ Technical Skills
  - 📊 Years of Experience
  - 🎓 Education Level
  - 🧑‍💼 Experience Level (Junior / Mid / Senior)
  - 🏆 Key Achievements
  - 🏭 Domain Expertise

## ⚙️ Tech Stack

- **Python**
- **Swarms** framework for agent orchestration
- **Ollama** for local LLM hosting (e.g., `llama2`, `mistral`, etc.)
